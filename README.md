# OIBSIP- project has three folders
### 🚀 Level 1 & Level 2 Project Overview
* **Level 1 (Core Web Foundations):** Focuses on mastering fundamental web building blocks (HTML5, CSS3, and JavaScript) by developing responsive, accessible, and structured single-page applications, including a SaaS Landing Page, Personal Portfolio, and Temperature Converter.
* **Level 2 (Dynamic Applications & State Management):** Advances into complex UI logic, component state handling, asynchronous operations, dynamic DOM manipulation, browser storage (`localStorage`), and client-side security (SHA-256 hashing) across a Browser Calculator, Interactive Tribute Page, Task Management To-Do App, and Login Authentication System.
