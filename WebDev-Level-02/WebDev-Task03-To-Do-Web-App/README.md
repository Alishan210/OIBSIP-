# To-Do Web App

## Overview
This project is a productivity-based web application for managing daily tasks. It supports adding, editing, deleting, and organizing tasks while preserving them in the browser using local storage.

## Project Details
- Level: WebDev Level 02
- Task: To-Do Web App
- Type: Frontend Productivity Project

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Font Awesome icons

## Features
- Add new tasks
- Mark tasks as complete or pending
- Edit tasks inline
- Delete tasks permanently
- View pending and completed task sections
- Display task counts and timestamps
- Persist data using localStorage
- Responsive layout for desktop and mobile

## Project Structure
```bash
WebDev-Task03-To-Do-Web-App/

```

## How to Run
1. Open the project folder.
2. Launch `Index.html` in your browser.
3. Or use Live Server in VS Code for preview.

## Usage
This app is useful for everyday task organization and is a practical frontend project for learning JavaScript DOM manipulation and browser storage.
