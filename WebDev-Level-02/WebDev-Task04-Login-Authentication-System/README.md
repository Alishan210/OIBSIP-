# Login Authentication System

## Overview
This project is a client-side login and registration system that allows users to create accounts, log in securely, and access a protected dashboard area. It demonstrates user validation, password hashing, and session-based access control.

## Project Details
- Level: WebDev Level 02
- Task: Login Authentication System
- Type: Frontend Security Project

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Web Crypto API
- Font Awesome icons

## Security and Functional Features
- User registration and login forms
- Password hashing using SHA-256
- Password strength validation
- Duplicate username/email checking
- Generic authentication error messages
- Protected dashboard access
- Session management using localStorage
- Logout functionality

2. Launch `Index.html` in your browser.

## Usage
This project is a frontend authentication sample and is useful for learning secure client-side user flow design, session handling, and form validation.
