# Calculator Web Application

## Overview
This project is a browser-based calculator that supports basic arithmetic operations, percentage calculations, keyboard input, and error handling for invalid expressions such as division by zero.

## Project Details
- Level: WebDev Level 02
- Task: Calculator
- Type: Frontend Utility Project

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Percentage and sign toggle support
- Keyboard controls for numbers and operators
- Clear and backspace functionality
- Error handling for invalid calculations
- Responsive keypad layout

## Project Structure
```bash
WebDev-Task01-Calculator/
├── Index.html
├── style.css
├── script.js
├── README.md
```

## How to Run
1. Open the project folder.
2. Launch `Index.html` in your browser.
3. You can also use Live Server in VS Code for a smoother preview.

## Usage
This calculator is suitable for simple arithmetic tasks and is a great frontend JavaScript practice project.
