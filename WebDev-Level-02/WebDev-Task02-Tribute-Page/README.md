# Tribute Page

## Overview
This project is a responsive tribute page designed to honor an influential person through a clean layout, biography sections, timeline highlights, and supporting visual elements.

## Project Details
- Level: WebDev Level 02
- Task: Tribute Page
- Type: Frontend Informational Project

## Tech Stack
- HTML5
- CSS3
- Google Fonts
- Font Awesome icons

## Features
- Hero section with image and title
- Biography and life timeline
- Highlights of achievements and legacy
- Quote or editorial section
- Responsive layout for multiple screen sizes

## Project Structure
```bash
WebDev-Task02-Tribute-Page/
├── index.html
├── style.css
├── README.md
```

## How to Run
1. Open the project folder.
2. Launch `index.html` in your browser.
3. You may also use Live Server in VS Code for easy preview.

## Usage
This page is ideal for personal, historical, or inspirational profile presentations and can be adapted for many tribute-style webpages.
