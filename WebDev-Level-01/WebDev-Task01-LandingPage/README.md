
# TechFlow SaaS Landing Page

## Overview
This project is a responsive SaaS landing page designed to showcase a modern tech product. It includes a strong hero section, feature highlights, pricing cards, and a polished footer with social links.

## Project Details
- Level: WebDev Level 01
- Task: Landing Page
- Type: Frontend Web Project

## Tech Stack
- HTML5
- CSS3
- JavaScript (if used in the page behavior)
- Font Awesome icons
- Google Fonts

## Features
- Modern hero section with headline and call-to-action buttons
- Product feature grid layout
- Pricing section with subscription cards
- Responsive design for mobile, tablet, and desktop
- Social media links in the footer

## Project Structure
```bash
WebDev-Task01-LandingPage/
├── Index.html
├── style.css
├── README.md
```

## How to Run
1. Open the project folder.
2. Launch `Index.html` in your browser.
3. Or use a live preview extension such as Live Server in VS Code.

## Usage
This landing page can be used as a starting template for product websites, startup promotion pages, or SaaS marketing sites.
