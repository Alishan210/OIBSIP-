# Temperature Converter Website

## Overview
This project is a simple temperature conversion web app that allows users to convert values between Celsius, Fahrenheit, and Kelvin. It includes validation, instant conversion, and a clean responsive interface.

## Project Details
- Level: WebDev Level 01
- Task: Temperature Converter
- Type: Frontend Utility Project

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Mathematical Formulas Used
- Celsius to Fahrenheit: `°F = (°C × 9/5) + 32`
- Celsius to Kelvin: `K = °C + 273.15`
- Fahrenheit to Celsius: `°C = (°F - 32) × 5/9`
- Fahrenheit to Kelvin: `K = ((°F - 32) × 5/9) + 273.15`
- Kelvin to Celsius: `°C = K - 273.15`
- Kelvin to Fahrenheit: `°F = ((K - 273.15) × 9/5) + 32`

## Features
- Multi-unit temperature conversion
- Input validation for invalid values
- Accurate result formatting
- Reset button for quick clearing
- Responsive card-based UI
