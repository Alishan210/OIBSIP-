# Personal Portfolio Website

## Overview
This project is a responsive personal portfolio website created to highlight a developer's skills, projects, experience, and contact information in a professional and visually appealing layout.

## Project Details
- Level: WebDev Level 01
- Task: Personal Portfolio
- Type: Frontend Portfolio Project

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts

## Features
- Professional landing section with introduction and call-to-action buttons
- Skills section for frontend technologies
- Project showcase cards
- Contact section with social links and contact details
- Responsive layout for desktop, tablet, and mobile devices

## Project Structure
```bash
WebDev-Task02-Personal-Portfolio/
├── Index.html
├── style.css
├── README.md
```

## How to Run
1. Open the project folder.
2. Launch `Index.html` in your browser.
3. You can also use Live Server in VS Code for a better preview.

## Usage
This portfolio is suitable for personal branding, job applications, freelance profiles, and showcasing technical work to employers or clients.
